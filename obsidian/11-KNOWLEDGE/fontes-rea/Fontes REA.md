# Fontes REA — índice

Notas de fonte escritas pelo [[Batedor REA]], uma por pergunta de uma hipótese. Cada nota traz:
- a hipótese ou o EXP que ela atende;
- a URL e a hora UTC;
- o método: REA, bundle, HTTP verificada ou inferência;
- as rotas e os campos, cada um com a etiqueta **observada / no bundle / verificada / inferência**;
- se o dado vale como ponto no tempo (`known_at`) ou só daqui para a frente;
- como o site faz a feature, numa descrição própria;
- os limites.

Nomes de usuário não entram; endereços entram truncados.
