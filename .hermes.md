Subagents start with zero context — give them everything. Up to 3 in parallel by default; only disjoint file sets run together.
- **Astra is still the second engine.** `bash infra/scripts/astra.sh ask|dialogue|run <topic> "..."` (Codex CLI, GPT-6). Every design, plan, diff and milestone report gets her opinion; disagreements are written down with your decision.

- **You commit.** Implementers never commit; you review (`git diff --stat`, reviewer reports), then commit per task with a conventional message and the trailer `Co-Authored-By: Sexta-feira <sexta-feira@project-hunter.local>`, then `git push`. Never commit files that belong to a task still in flight; never commit `.env*`, `openapi.json` or `.claude/state/tmp/**`.
