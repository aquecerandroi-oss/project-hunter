# 0002 — Camada de provedores LLM com Anthropic e OpenAI (GPT-6 Astra)

- **Status:** aceito (implementação na Fase 2, Intelligence Engine)
- **Data:** 2026-09-04
- **Contexto:** a especificação (§37) prevê LLMs para classificação de notícias, extração de entidades, narrativa, sentimento, resumo e explicação, com a Anthropic como provedor inicial. Em 2026-09-03 a OpenAI lançou o GPT-6 Astra (id de API `gpt-6-astra`, contexto de 1M tokens, US$ 10/50 por milhão de tokens de entrada/saída, disponível na API da OpenAI, Azure e Bedrock). O produto quer poder usar os dois. Nenhuma IA pode entrar no caminho Risk Engine → Execução (§37, `CLAUDE.md`).
- **Decisão:** implementar uma camada `hunter_core.llm` provedor-agnóstica: `LlmProvider` (Protocol) com `AnthropicProvider` e `OpenAIProvider`; seleção por configuração (`LLM_PROVIDER=anthropic|openai`, `LLM_MODEL` com padrão por provedor: `claude-opus-5` e `gpt-6-astra`); chaves só em variáveis de ambiente (`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`), nunca no frontend; toda chamada registra provedor, modelo, tokens e custo em `intelligence_events`/logs; saídas são **dados classificados** (JSON validado por Pydantic), nunca instruções; conteúdo externo (notícia, post) entra como dado citado, nunca interpolado como instrução (proteção contra prompt injection, §36). A escolha de provedor pode ser por tarefa (ex.: classificação em massa num modelo barato, explicações num modelo forte), sempre com fallback e circuit breaker: LLM indisponível degrada para "sem análise", nunca para decisão automática.
- **Alternativas consideradas:** só Anthropic (mais simples, mas prende o produto a um fornecedor e impede comparação de qualidade); roteador externo (OpenRouter e similares: adiciona um terceiro na cadeia de segredos e de dados de mercado); usar o GPT-6 Astra como agente de desenvolvimento neste fluxo (não se aplica: o fluxo de desenvolvimento roda no Claude Code; Astra entra como IA dentro do produto).
- **Consequências:** entram no `.env.example` `OPENAI_API_KEY`, `OPENAI_MODEL`, `LLM_PROVIDER`, `LLM_MODEL`; a flag `ENABLE_LLM_ANALYSIS` continua desligada no MVP; testes da camada usam provedores falsos (sem rede); custo por chamada vira métrica Prometheus (`hunter_llm_tokens_total{provider,model,direction}`); avaliação comparativa entre modelos passa a ser possível no Learning Engine. Revisar após a primeira semana de uso real na Fase 2: custo por 1.000 notícias e taxa de JSON inválido por provedor.
- **Referências:** `docs/ARCHITECTURE.md` §2 (linha LLM), `docs/SECURITY.md` (segredos, prompt injection), [anúncio do GPT-6 Astra](https://openai.com/index/gpt-6-astra/), [documentação do modelo na API](https://developers.openai.com/api/docs/models/gpt-6-astra), [cobertura CNBC](https://www.cnbc.com/2026/09/03/open-ai-astra-gpt-6-cyber.html).
