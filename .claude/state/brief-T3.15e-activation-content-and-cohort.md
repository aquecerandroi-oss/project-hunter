## Deliver
1. **`activate` of a derived line freezes the row's content, not the build's** (`infra/scripts/activate_strategy_version.py`, `activate()`): today it writes `parameters_schema`/`default_parameters`/`params_format` from the code the registry resolves — correct for a research version seeded from code, wrong for a `paper` line whose content was copied byte for byte from the frozen research row (T3.15, D10 "parâmetros copiados bit a bit"). Rule: when the row already carries content **and** `purpose != research_only` (or, more generally, when the row was derived — `changelog` starts with `paper line of`), activation validates the row's own parameters against the row's own schema, confirms the recomputed `code_ref` equals the row's `code_ref` (refuse otherwise: "deploy the matching build or derive again"), and writes **only** `status`, `activated_at`, `changelog`. Tests in `services/strategy-worker/tests/test_activate_paper_line.py`: derive → activate (`dry_run=False`) → the paper row's schema/params/params_format are identical to the research row's; a build whose code drifted is refused; the research row untouched.
2. **The bridge admits one cohort** (`services/execution-worker/hunter_execution_worker/bridge_repo.py`/`bridge_screen.py`): filter `agent_signals` to the live cohort of the version (never `replay:*` or any other synthetic cohort — read how cohorts are named in `services/strategy-worker/hunter_strategy_worker/record.py` and the replay R1 code) and refuse anything else with reason `cohort_not_live`. Test: a replay-cohort signal of a `paper` version is refused; the live-cohort one passes.
3. **`purpose` is visible**: `VersionSummaryOut` (and whatever the Lab/strategy pages list) carries `purpose`; the web shows the label (`research_only` → "pesquisa", `paper` → "paper", `live` → never expected) as a chip next to the version. Small; keep to the existing components. Tests on both sides.
4. **Measure the worker cycle headroom** (D10 condition): with the execution-worker running on the local stack, record for 10 min the admission cycle duration (p50/p95/max) and the MTM cycle duration against their budgets (1 s and 60 s); paste the numbers in `.claude/state/notes-T3.15e.md`. No code change unless a cycle exceeds its budget — then report, do not fix here.
