# Brief T3.64 — Plantão de mercado (recorrente): um agente varre a internet num circuito definido de fontes sobre cripto (pesquisa, dados, fóruns, notícias de mercado), documenta no Obsidian com procedência, discute cada leva com a Astra, e entrega hipóteses testáveis para o Lab (Everton, 2026-09-09 16:40: "fica se atualizando na internet inteira… documente no Obsidian… discuta com a Astra… o Lab vai aprender a usar tendências")

**Owner:** general-purpose agent with web access (one run per fire). **Recurrence:** every hour while this session lives (CronCreate "17 * * * *", 7-day limit — the orchestrator re-arms it; each lane comes around every 4 h; a run that finds the previous one still working is skipped and logged), plus on demand. Budget per run ≤ 30 min. **Never commits; the orchestrator commits the batch.** **Operational rule: never a background shell; every command foreground with explicit `timeout 290`; no testcontainers; the tree is shared — never `git stash`/`checkout --`/`restore`/`reset`/`clean`/`commit -a` (git-guard blocks); do not touch `.env*`; write ONLY under `.claude/state/plantao/` (drafts + run log) and `obsidian/02-MARKET/Plantao/`, `obsidian/11-KNOWLEDGE/` (KB-* notes), `obsidian/00-INBOX/Hipoteses-do-plantao.md`; never invent a number or a quote — every claim carries the URL actually opened and the date read; if a page cannot be opened, say so and drop the claim.**

## Honesty about scope
"A internet inteira" is not a circuit; a circuit is. Each run covers ONE of the four lanes below (rotate by run number stored in `.claude/state/plantao/run-counter.txt`) so that in a day the four are covered:
1. **Pesquisa e dados** — arXiv q-fin (crypto, market microstructure, momentum/reversal), SSRN new crypto papers, Kaiko / Glassnode / CryptoQuant / Coin Metrics research posts, Binance Research, exchange blogs on fee/funding changes.
2. **Notícias de mercado e macro cripto** — CoinDesk, The Block, Cointelegraph (markets section), Bloomberg/Reuters crypto (headlines), regulatory and ETF flows, exchange incidents/outages, stablecoin events.
3. **Fóruns e praticantes** — r/algotrading, r/CryptoMarkets, r/BitcoinMarkets, QuantConnect/Forum, EliteTrader crypto threads, Nostr/X threads only via search snippets (never log in), Hacker News crypto/quant threads.
4. **Ferramentas e concorrentes** — Freqtrade/Hummingbot/Jesse releases and strategy discussions, TradingView public ideas on BTC/ETH (what retail is drawing), open-source strategy repos with results.

## Deliver per run (≤ 45 min of work)
1. `.claude/state/plantao/YYYY-MM-DD-HHMM-lane<N>.md`: 5–12 items; each = título · fonte (URL aberta) · lido_em (BRT) · o que afirma (≤ 3 linhas) · evidência (dado/amostra/método ou "opinião") · relevância para o Hunter (qual módulo/estratégia/KB) · **hipótese testável ou "painel"**. Ranking by relevance; the top 3 get a "por que agora".
2. **Astra**: `bash infra/scripts/astra.sh ask plantao-YYYYMMDD-HHMM "<the 3 top items + the question: qual destas você testaria primeiro no Lab e por quê; o que está errado ou é hype>"` (timeout 290; if Astra is unavailable, say so once and continue). Write her answer's essence and the disagreement, if any, into the draft.
3. **Obsidian**: append the run to `obsidian/02-MARKET/Plantao/YYYY-MM-DD.md` (one file per day, sections per run, template of `_TEMPLATE-NOTE.md` frontmatter at the top of the day file); when an item deserves a standalone note (a paper with numbers, a structural market change), write `obsidian/11-KNOWLEDGE/KB-00NN-<slug>.md` with the template and add the row to `Index.md` (next free KB number — check `ls obsidian/11-KNOWLEDGE`).
4. **Fila de hipóteses**: append to `obsidian/00-INBOX/Hipoteses-do-plantao.md` a table row per testable hypothesis: data · hipótese (uma frase) · fonte · como testar no Lab (qual estratégia/variante, qual métrica, qual régua) · status (`nova`). The orchestrator turns `nova` into a brief or marks `descartada` with the reason. A hypothesis is never applied to a live strategy directly — the funnel (contract → replay → stress → prospective) is the only door.
5. `uv run python infra/scripts/obsidian_lint.py` clean for the files written; `.claude/state/plantao/run-log.md` gets one line (run, lane, items, KBs, hypotheses, Astra ok/indisponível).

## Prove
The draft file, the lint output, the Astra transcript path; report in Portuguese, ≤ 20 lines. Times in Brasília (UTC−3).
